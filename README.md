## About the Project

This is a **Music Store Data Analysis** project that I built using **SQL** and **MySQL**. The objective of this project was to analyze a music store database and extract meaningful business insights by solving real-world business questions.

I designed the relational database, established relationships between tables, imported datasets, and wrote SQL queries to analyze customer behavior, sales performance, artist popularity, and music trends.

---

## 🗄️ Database Schema

The Music Store database is designed using a relational model consisting of customers, invoices, tracks, albums, artists, genres, playlists, and employees.

## Project Overview

The project analyzes various business aspects of a music store database, including:

- Customer Analysis
- Sales Analysis
- Invoice Analysis
- Artist Performance
- Album Analysis
- Genre Analysis
- Employee Analysis

---

## Business Questions Solved

- Who is the senior-most employee based on job title?
- Which countries generate the highest number of invoices?
- What are the top invoice values?
- Which city generates the highest revenue?
- Who is the best customer based on total spending?
- Which artists have written the most Rock music?
- Which tracks are longer than the average song length?
- How much has each customer spent on different artists?
- What is the most popular music genre in each country?
- Which customer has spent the most on music in each country?
